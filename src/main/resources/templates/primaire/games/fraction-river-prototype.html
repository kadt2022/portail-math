La Rivière des fractions — version illustrée

Trois couches : l’illustration porte le décor, Phaser anime le chien, l’eau, les oiseaux et les poissons, le HTML pose les questions. Le moteur pédagogique est celui du jeu existant — mêmes défis, mêmes distracteurs, mêmes indices. Les cinq pierres sont peintes : elles montrent le trajet dès la première seconde, et un halo s’allume sur celle qui vient d’être gagnée. Le chien est encore un dessin de remplacement fait au code, en attendant sa vraie feuille d’animation. Ajouter ?debugAnchors=true à l’adresse affiche la grille de calibrage.
